# Оптимизация `@bothub-chat/ui`: что сделано и что осталось

Ветка: `claude/determined-mccarthy-m0lc4a`. Сайдбар в ней не трогали; его сворачивание переделано в `claude/architecture` (см. ниже).

Цифры ниже — замеры на стенде (vitest + jsdom). В браузере абсолютные значения меньше, но соотношения и счётчики (слушатели, observer'ы, ререндеры, CSS-классы) точные. Исключение — стоимость стилей styled-components: под vitest он работает в режиме разработки и хэширует весь CSS компонента, а в production — только результат интерполяций. Такие оптимизации проверены в Chromium на production-сборке.

- [x] Токены `theme.tokens.*`: семантические цвета `{ light, dark }` (или функция темы, если важна ещё и схема) вычисляются один раз при создании темы вместо `theme.mode === 'light' ? … : …` в каждом стиле. Около 55 токенов: поверхности, рамки, текст, акценты, цвета сообщений, полупрозрачные версии цветов
- [x] ~90 ветвлений по `theme.mode` (и `scheme` + `mode`) в 48 файлах заменены токенами; `colorToRgba(...)` и склейка `${accent}33` в стилях — тоже токены
- [x] `ThemeProvider` всегда пересчитывает токены пользовательской темы (`customTheme`), превью тем — свои
- [x] `themeVar(theme, 'colors.…')` в 682 местах (125 файлов): литеральный цвет или `var(--bothub-…)`
- [x] Опция `cssVariables` у `ThemeProvider` / `BothubUIProvider`: корневой провайдер выставляет все цвета, `default.colors` и токены переменными на `:root`; вложенные провайдеры и превью тем остаются на литеральных цветах
- [x] Проверено на CSS всех stories в 14 схемах × 2 режима (8260 рендеров): без опции CSS не изменился, с опцией после подстановки переменных совпадает с исходным
- [x] Результат в Chromium (40 сообщений и ~100 компонентов): первое переключение на новую тему — 5 новых CSS-правил вместо 129 и 59 мс вместо 92; CSS одинаков в dark и light у 192 из 295 stories (было 19)

### Как включить
```tsx
<BothubUIProvider theme={{ mode, scheme, cssVariables: true }}>
```
В новых стилях: `${({ theme }) => themeVar(theme, 'tokens.surfaceElevated')}` или `themeVar(theme, 'colors.grayScale.gray4')`. Для вычислений в JS (`colorToRgba`, `isBright`) берите цвет напрямую из `theme` или заведите токен в `theme/tokens.ts`.

Без переменных CSS тот же, кроме этих явных `none`
